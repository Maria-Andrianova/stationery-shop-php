# Интернет-магазин канцелярии

Учебный проект: сайт магазина канцелярских товаров на PHP и MySQL.

## Возможности

- главная страница с обзором продукции
- каталог товаров и страница товара с описанием и характеристиками
- регистрация и вход, пароли хранятся в виде хеша (`password_hash`)
- список покупок: добавление товара, изменение количества, удаление
- форма обратной связи, сообщения сохраняются в базе данных
- страница «О нас»
- запросы к базе данных выполняются через подготовленные выражения

## Структура

- `database.sql` — создание базы `stationery_shop`: таблицы пользователей, товаров, списка покупок и обратной связи, тестовые товары
- `src/` — файлы сайта:
  - `index.php`, `shop.php`, `product.php`, `about.php` — страницы сайта
  - `login.php`, `register.php`, `auth.php`, `register_process.php`, `logout.php` — вход и регистрация
  - `cart.php`, `add_to_cart.php`, `update_cart.php`, `remove_from_cart.php` — список покупок
  - `feedback.php` — обратная связь
  - `header.php`, `footer.php`, `style.css` — общие части оформления
  - `database.php` — подключение к базе данных
  - `images/` — изображения товаров

## Запуск

Нужен XAMPP (Apache и MySQL).

1. Скачать репозиторий.
2. Создать папку `C:\xampp\htdocs\shop` и скопировать в неё содержимое папки `src`.
3. Запустить Apache и MySQL в панели управления XAMPP.
4. Открыть http://localhost/phpmyadmin, на вкладке «Импорт» выбрать файл `database.sql` и выполнить импорт.
5. Открыть в браузере http://localhost/shop/

В `src/database.php` указаны стандартные настройки XAMPP (пользователь `root`, пароль пустой). Если настройки MySQL другие, значения нужно изменить.
